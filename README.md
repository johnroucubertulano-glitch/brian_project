# Brian Project

## Summary
This project is an initial Flutter Web application with a home screen and a login screen. It serves as the starting point for developing the approved system.

## Current stack
Flutter Web / Dart; planned REST API and PostgreSQL.

## Run locally
Run these commands from the project root directory (`brian_project`):

```bash
flutter pub get
flutter run -d chrome
```
